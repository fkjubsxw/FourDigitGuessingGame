
# 猜四位数小游戏 🔢

一个基于 Python Tkinter 的图形化猜数字游戏。系统随机生成一个四位数，玩家需要在有限次数内猜中它，每次猜测都会得到“猜对了几位数字”的反馈。游戏会根据总猜测次数给出趣味评级（如“夯爆了”、“顶级”、“人上人”、“NPC”、“拉完了”），并附带一个“演草纸”窗口自动记录每次猜测的结果。

## 🎮 游戏规则

1. 系统会随机生成一个 **1000~9999** 之间的四位整数（无重复数字要求，每位独立）。
2. 玩家在输入框中输入一个四位数字，点击“查询”或按回车提交。
3. 系统会提示：
   - 若 **数字完全正确** → 游戏胜利，弹出祝贺窗口，并根据总猜测次数显示评级图片。
   - 若 **不完全正确** → 提示“你猜对了：x 个数字”，并将本次猜测的数字及正确个数自动记录到右侧“演草纸”窗口中。
4. 只能输入 **四位纯数字**，否则会弹出“输入不合法”警告。
5. 游戏胜利后，点击“拜拜”按钮即可关闭游戏窗口，回到主界面重新开始。

## 💡 特色功能

- **可视化界面**：使用 Tkinter 构建，窗口自适应屏幕大小，不可缩放。
- **实时演草纸**：自动记录每次猜测的数字和正确位数，方便玩家推理。
- **趣味评级**：根据完成游戏所用的总猜测次数，在胜利时展示不同等级的评语图片：
  - ≤5 次 → 「夯爆了」
  - 6~10 次 → 「顶级」
  - 11~15 次 → 「人上人」
  - 16~20 次 → 「NPC」
  - ≥21 次 → 「拉完了」
- **规则说明窗口**：主界面提供“help”按钮，点击可查看详细规则。
- **关闭确认**：主窗口关闭时会弹出二次确认，防止误操作。

## 🛠️ 运行环境与依赖

- **Python 版本**：3.6 及以上
- **依赖库**：
  - `tkinter`（Python 自带，无需额外安装）
  - `Pillow`（用于缩放 `祝贺.png` 以适应窗口大小）

安装 Pillow：
```bash
pip install Pillow
```

## 🚀 如何运行

1. 将上述所有图片文件与 Python 脚本放在同一文件夹中。
2. 打开终端/命令行，进入该文件夹。
3. 执行：
```bash
python 你的脚本文件名.py
```
4. 主界面出现后，点击 **start!** 开始新游戏，点击 **help** 查看规则。

## 📄 代码简介

- 主窗口 `a1`：欢迎界面，包含标题、装饰图、开始按钮和帮助按钮。
- 游戏窗口 `a3`：实际游戏界面，包含输入框、查询按钮、结果标签和评级图片展示。
- 演草纸窗口 `a6`：带有滚动条的文本框，自动记录每次猜测的数字和正确位数。
- 核心逻辑：
  - 随机生成四位整数 `x`，并拆分千、百、十、个位存入 `a,b,c,d`。
  - 比较用户输入的四位数各位与答案对应位，统计正确个数。
  - 完全正确时弹出胜利窗口，根据全局变量 `round_count` 显示对应评级图片。
- 关闭协议：主窗口、游戏窗口、祝贺窗口均有相应的关闭处理。

## 📝 注意事项

- 本游戏未实现“数字可重复”的特殊规则，每位独立比较位置（即顺序也必须一致）。
- 如果希望支持位置无关（数字相同但顺序不同也算对），可以自行修改比较逻辑。
- 图片加载若报错，请检查文件名大小写及扩展名是否与实际文件完全一致（Windows 不区分大小写，但 Linux/macOS 区分）。
